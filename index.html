    Save to GitHub

    Confirmed menus are saved as one file per day in the data folder of the repository. Until this is set up, everything is kept on this device and sent automatically once it works.

    How do I get a token?
    1. On GitHub open Settings → Developer settings → Personal access tokens → Fine-grained tokens and choose Generate new token.
    2. Under Repository access pick Only select repositories and choose this repository.
    3. Under Permissions → Repository permissions set Contents to Read and write.
    4. Generate, copy the token and paste it above. It stays only in this browser.

    Import menu history

    Upload the Excel / CSV file, or copy the rows from Google Sheets or Excel and paste them below. The app then works out the per-thaal quantity of every ingredient for every dish.

    What layout should the sheet have?

    One row per ingredient per menu. Column names don't have to match exactly; you can pick them after reading the data. Date, meal, thaals and menu only need to be on the first row of each menu.
